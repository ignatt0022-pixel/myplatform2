Настоящая Политика конфиденциальности (далее — «Политика») определяет порядок обработки и защиты информации о пользователях веб-платформы FiveCore (далее — «Сервис»).

1.2. Использование Сервиса означает полное согласие Пользователя с настоящей Политикой и указанными в ней условиями обработки его информации.

1.3. Если Пользователь не согласен с условиями Политики, он должен прекратить использование Сервиса.

2. Собираемые данные и цели их обработки

Сервис собирает и обрабатывает только тот минимальный объем данных, который необходим для обеспечения его работы:

  • Адрес электронной почты (Email): используется для регистрации, авторизации, идентификации Пользователя и обеспечения доступа к личному кабинету.
  • Пароль: используется для аутентификации. На серверах не хранится открытый текст пароля — обработке и хранению подлежит только его защищенный хэш.
  • Внутренний идентификатор (User ID): уникальный технический номер, автоматически генерируемый системой при регистрации для связывания учетной записи с прогрессом обучения.
  • Технические данные об обучении (Прогресс): список пройденных уроков и статистика ошибочных заданий. Данная информация используется исключительно для отображения обучающего прогресса Пользователю.

3. Хранение и передача данных третьим лицам

3.1. Первичный сбор, обработка и хранение учетных данных (Email, хэш пароля, User ID) осуществляются на серверах провайдера Yandex Cloud (ООО «Яндекс»), расположенных на территории Российской Федерации, в строгом соответствии с требованиями 152-ФЗ.

3.2. Для сохранения текущего обучающего прогресса и статистики ошибок используется инфраструктура Firebase (Google LLC). В Firebase передается исключительно обезличенный User ID и технические данные о пройденных уроках. Персональные данные (Email) в Firebase не передаются.

3.3. Администратор не передает персональные данные третьим лицам, за исключением случаев, прямо предусмотренных действующим законодательством РФ.

4. Файлы Cookie и локальное хранилище

4.1. Сервис использует файлы cookie и техническое локальное хранилище браузера (Local Storage / Session Storage) исключительно для сохранения текущей сессии авторизации Пользователя (чтобы не вводить Email и пароль при каждом переходе между страницами).

4.2. Сервис не использует cookie для отслеживания действий Пользователя на сторонних сайтах или в рекламных целях.

5. Безопасность данных

5.1. Администратор предпринимает необходимые технические и организационные меры для защиты персональных данных Пользователя от неправомерного или случайного доступа, уничтожения, изменения, блокирования, копирования и распространения.
